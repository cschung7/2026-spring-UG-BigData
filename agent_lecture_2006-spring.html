02
Motivation

왜 지금 Agent인가?

기존 LLM

  • 질문에 답변을 생성
  • 단발성 context 중심
  • 기억과 실행 권한이 약함
  • 사람이 계속 다음 지시를 내려야 함

Agent

  • 목표를 작업으로 분해
  • 도구를 호출하고 결과를 관찰
  • 메모리와 상태를 유지
  • 반복 업무를 스킬화
LLM은 지식을 생성했고, Agent는 업무를 수행하기 시작했다.

Core Difference

두 도구의 핵심 차이

Hermes Agent

Learning-loop-first

사용자의 반복 업무, 프로젝트 맥락, 선호를 기억하고 경험에서 스킬을 만들며 개선하는 자기개선형 에이전트 런타임.

07
Deep Dive · Hermes

Hermes Agent: 학습하는 에이전트

Persistent Memory

세션을 넘어 사용자·프로젝트·작업 이력을 축적한다.

Skill System

반복 절차를 재사용 가능한 스킬로 저장하고 호출한다.

Self-improving Loop

경험에서 성공 패턴을 발견하고 실행 방식을 개선한다.

Subagents

복수 작업 흐름을 병렬화하거나 역할별로 분담한다.

Scheduled Automation

정기 보고서, 모니터링, 반복 체크를 예약 실행한다.

MCP / Tools

외부 도구와 데이터 소스를 연결해 실제 작업을 수행한다.

08
Deep Dive · OpenClaw

OpenClaw: 로컬 우선 게이트웨이

Local-first

사용자 장치나 서버에서 실행되며 파일과 세션을 직접 통제한다.

Messaging Router

Slack, Telegram, Discord 등 여러 채널을 하나로 묶는다.

Model Agnostic

OpenAI, Anthropic, Google, OpenRouter, Ollama 등 모델 선택 자유가 크다.

Browser / Shell

브라우저 자동화, 파일 처리, 셸 실행을 연결한다.

Daemon Mode

항상 켜져 있는 개인 비서처럼 운영할 수 있다.

Explicit Control

스킬, 라우팅, 설정을 사용자가 명시적으로 관리하기 쉽다.

Economics

경제학 관점: Coase와 Agent

기업은 왜 존재하는가? 거래비용을 줄이기 위해서다. Agent는 정보 탐색, 보고, 조정, 커뮤니케이션 비용을 낮춘다.

가능한 변화

  • 더 작은 조직도 큰 조직 수준의 반복 분석 가능
  • middle coordination layer 일부 감소
  • AI-native firm의 등장
  • 개인과 조직의 운영 레버리지 확대

경제적 효과

정보비용 절감
공시, 뉴스, 리서치, 내부 문서 요약

거래비용 절감
보고, 승인, 커뮤니케이션 자동화

제한합리성 보완
다량 정보의 기억·검색·비교

Key Takeaway

핵심 메시지

Agent 시대의 핵심 문제는 intelligence보다 governance이다.

Hermes의 의미

개인의 기억, 절차, 스킬이 누적되는 학습형 업무 런타임.

OpenClaw의 의미

로컬 환경과 메시징 채널을 연결하는 개인 AI 조종석.

Conclusion

결론

Hermes와 OpenClaw는 경쟁 도구이기도 하지만, 실제로는 개인 AI 인프라의 두 방향을 보여준다.

Hermes Agent

“에이전트가 시간이 지날수록 나를 더 잘 이해하고 반복 업무를 개선하길 원할 때.”

OpenClaw

“여러 채널과 로컬 도구를 연결한 강력한 개인 AI 조종석을 원할 때.”

AI Agent는 검색 엔진 → 모바일 → 클라우드 이후의 새로운 개인 컴퓨팅 패러다임 실험이다.
